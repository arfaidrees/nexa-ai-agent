# Return Policy

Nexa Electronics accepts return requests within 14 calendar days of delivery.

Products must be unused, in resalable condition, and include the original box, accessories, and proof of purchase. Opened products can be returned only when they are defective or damaged on arrival. Change-of-mind returns are not accepted after a product has been opened or activated.

To request a return, contact support with the order number and photos when relevant. Approved refunds are issued to the original payment method after inspection. Delivery charges are refundable only for defective, incorrect, or damaged items.
